---

## ✨ Features

- **🎨 Modern Glassmorphism Design**: Sleek dark mode palette with glowing purple/blue gradients and interactive glass cards.
- **📄 Interactive Live CV / Resume Modal**: In-browser PDF preview with instant 1-click download and open-in-tab options.
- **📋 One-Click Email Copy**: Clickable contact pill that copies the email address to clipboard with a toast notification.
- **📱 Fully Responsive**: Optimized for desktop, tablets, and mobile screens with an animated mobile navigation drawer.
- **⚡ Zero Build Dependencies**: Ultra-fast static site loading pure HTML5, vanilla CSS3, and modern JavaScript.
- **🌐 SEO & Social Ready**: Meta tags configured for fast indexing and clean sharing previews.

## 💻 Getting Started Locally

No package managers or external dependencies needed!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SharathLNaik/sharath-portfolio.git
   cd sharath-portfolio
   ```

2. **Open with Live Server or directly in your browser:**
   - Double-click `index.html` to open in any web browser.
   - Or with VS Code: right-click `index.html` and select **"Open with Live Server"**.

---

## 🚀 Deployment to Vercel

This repository is optimized for instant zero-config deployment on Vercel:

1. Import this repository into [Vercel](https://vercel.com/new).
2. Keep the Framework Preset as **Other**.
3. Click **Deploy**.
